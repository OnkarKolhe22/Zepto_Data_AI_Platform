
# Zepto Data & AI Platform

## Project Overview
This capstone project demonstrates data collection, data analytics, machine learning, and an AI-powered support assistant.

## Project Modules

### Module 1: Data Pipeline
- Web scraping
- Data cleaning
- SQLite database
- SQL queries and pandas analysis

### Module 2: Analytics
- Exploratory Data Analysis
- Data visualization
- Machine learning classification
- Fare prediction regression

### Module 3: Support Assistant
- Document embeddings
- Vector database
- Retrieval-Augmented Generation (RAG)
- LangGraph workflow
- FastAPI application

## Technologies Used
Python, Pandas, NumPy, BeautifulSoup, SQLite, Scikit-learn, Matplotlib, Seaborn, ChromaDB, LangGraph, FastAPI.

## Project Structure
- data_pipeline/
- analytics/
- support_assistant/
